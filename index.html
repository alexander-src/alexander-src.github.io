STUDY 01 / SHIPPED V0.1.0 / MULTI-OS CI PASSING

isa-audit

Zero-dependency, #![forbid(unsafe_code)] Rust x86-64 ELF64 binary ISA feature auditor and CI verification gate. Catches accidental SIGILL instructions (FMA3, AVX2, AVX-512) inside portable release binaries and instruction-lowering passes with exact section, virtual address, symbol offset, and raw machine bytes.

  • Decode throughput281.6 MiB/s (70.1M insns/s)
  • Binary footprint427 KB stripped release
  • External crates / unsafe0 crates / forbidden
  • Verification oracle6 live g++ -O2 kernels + objdump
  • Real bugs caughtET_REL st_value==0 & tzcnt (rep bsf)
