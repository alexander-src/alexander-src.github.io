Selected project

isa-audit

Rust, v0.2.0 (2026)

A zero-dependency x86-64 ELF64 binary auditor and CI gate written in safe Rust (#![forbid(unsafe_code)]). It scans executable ELF sections, decodes legacy, REX, VEX, and EVEX encodings, compares build-to-build ISA regressions via isa-audit diff --fail-on-regression, and fails CI with exact addresses and symbol offsets if forbidden extensions (such as FMA3, AVX2, or AVX-512) slip into portable binaries or instruction-lowering passes.

Compiled release binary is 427 KB and decodes /usr/bin/objdump at 281.6 MiB/s (70.1 million instructions per second) with zero recovery steps. Tested in GitHub Actions across Linux, macOS, and Windows alongside six live g++ -O2 kernel compilations, with automated prebuilt binaries and SHA-256 checksums published on GitHub Releases.
